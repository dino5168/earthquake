
# 需求描述

## 震源深度分類

地震可能發生在地表以下至 700 公里的深度範圍。為了科學研究與統計的目的，依據地震的震源深度，將地震分為以下四種類型：

0 - 30km

極淺地震

Very Shallow

30 - 70km

淺層地震

Shallow

70 - 300km

中層地震

Intermediate

300 - 700km

深層地震

Deep

## 坐標軸顯示

Z軸加深度。XY軸加經度。

# 實作計畫書（2026-11-10 草擬）

## 現況（`9-Project/viz/eq-3d`）
- 點色：`colormap.ts` 的 `DEPTH_STOPS` 連續漸層（0→300 km，紅→黃→綠→青→藍）。
- 外框：`layers/frame.ts` 白色線框，經度 118–124°E、緯度 20–27°N、深度 0–320 km（`FRAME_DEPTH_KM`），**沒有任何刻度與文字**。
- 場景座標：three.js Y-up，`+x = 東`、`+y = 上（-深度）`、`-z = 北`；深度倍率透過 `object.scale.y`。
- 資料分佈（73,729 筆，ML ≥ 3，最大深度 313.2 km）：

| 類型 | 深度 | 筆數 | 比例 |
|---|---|---|---|
| 極淺地震 Very Shallow | 0–30 km | 50,472 | 68.5% |
| 淺層地震 Shallow | 30–70 km | 14,068 | 19.1% |
| 中層地震 Intermediate | 70–300 km | 9,187 | 12.5% |
| 深層地震 Deep | 300–700 km | 2 | <0.01% |

## 名詞對應
需求的「Z 軸 = 深度、XY = 經緯度」是地學慣例；對應到 three.js：
- 地學 X（經度）→ scene `x`
- 地學 Y（緯度）→ scene `-z`
- 地學 Z（深度）→ scene `-y`
> 假設「XY軸加經度」意指 X = 經度、Y = 緯度。

## A. 震源深度分類
1. `colormap.ts`：新增資料驅動的 `DEPTH_CLASSES`（`{ id, min, max, nameZh, nameEn, color }` × 4）與 `depthClassOf(depthKm): number`。
   - 顏色採用 CWA 地震百問 14〈何謂淺層地震、深層地震?〉（https://scweb.cwa.gov.tw/zh-tw/guidance/faqdetail/14）的 `.level-N::before` 色碼：
     極淺 `#ef4444` 紅、淺層 `#f59e0b` 橘、中層 `#3b82f6` 藍、深層 `#1e3a8a` 深藍。
   - 點色**完全改為 4 類離散色**，移除連續漸層 `DEPTH_STOPS`（地形的 `ELEVATION_STOPS` 保留）。
   - 邊界採左閉右開 `[min, max)`；深度 < 0（少數 CWA 資料）歸入極淺，≥ 700 歸入深層。
2. `layers/points.ts`：新增 `aClass` attribute（Float32，0–3）與 `uClassMask` uniform（vec4，1 = 顯示）；shader 隱藏條件多加一項。顏色改用分類色。
3. `ui.ts`：
   - 新資料夾「深度分類」，4 個 checkbox 控制顯示（顯示各類筆數）。
   - 圖例 `renderLegend` 改為 4 個離散色塊 + 中英文名稱 + 深度區間 + 筆數。
4. 外框加上 30 / 70 / 300 km 的分類界面淡色水平線（深度層一目了然）。

## B. 座標軸
1. 新增 `layers/axes.ts`：`createAxes(depthKm): THREE.Group`，內容：
   - 刻度線（`LineSegments`）：經度沿外框底面南緣、緯度沿東緣（實測時發現放在西緣會和深度軸重疊，所以改到東緣），經度 118–124°E、緯度 20–27°N，每 1°。
   - 深度軸：外框西南角垂直邊，刻度 0 / 30 / 70 / 100 / 200 / 300 km（含分類邊界）。
   - 文字標籤：three.js 內建 `CSS2DRenderer`／`CSS2DObject`（`three/addons`，不新增依賴），軸標題「經度 (°E)」「緯度 (°N)」「深度 (km)」。
2. 深度標籤掛在 group 內並與點雲共用 `scale.y`，深度倍率改變時自動跟著移動，標籤文字仍顯示真實 km。
3. `main.ts`：建立 `CSS2DRenderer` 疊在 WebGL canvas 上（`pointer-events: none`，不擋 OrbitControls），resize 一併處理。
4. `ui.ts`：「座標軸」顯示開關；`style.css` 加 `.axis-label` 樣式；手機寬度縮小字級。

## C. 測試（vitest）
- `depthClassOf`：邊界值 0、29.9、30、70、300、700、負深度。
- `DEPTH_CLASSES` 連續且無重疊。
- 刻度產生函式（純函式，抽出可測）：經緯度刻度數量與數值。

## 可行性評估
| 項目 | 評估 |
|---|---|
| 技術風險 | 低。全部在 eq-3d 前端內完成，不動資料管線、後端、Leptos。 |
| 效能 | `aClass` 多 73k × 4 bytes；CSS2D 標籤約 25 個，可忽略。 |
| 依賴 | 無新增套件（CSS2DRenderer 隨 three 提供）。 |
| 相容性 | iframe 嵌入、手機收合面板沿用既有機制。 |
| 規模 | `ui.ts` 預計 ~150 行、`axes.ts` ~120 行，皆在上限內。 |
| 工時 | 約半天（含測試、文件）。 |

**注意**：深層地震（300–700 km）資料中只有 2 筆，外框底部目前在 320 km；若外框延伸到 700 km，下半部幾乎全空、淺層被壓扁。建議外框維持 320 km，深層類別仍保留在圖例與篩選中。

## 決議（2026-11-10）
1. 點色：使用 CWA FAQ 14 的 4 類配色（使用者提供的 faqdetail/34 是規模分類，深度分類在 faqdetail/14）。
2. 外框深度：維持 320 km。
3. 座標軸：X = 經度、Y = 緯度、Z = 深度。

**配色風險**：深層 `#1e3a8a` 在深色背景 `#05070d` 加上 additive blending 時幾乎看不見（只有 2 筆）。使用者決定：點雲改用 `#60a5fa`，圖例仍用原色。
